Contributing

PiNum is open source and MIT-licensed — any help is welcome, from bug reports to pull requests.

On this page

Ways to contribute

  • Report bugs — open an issue on GitHub with a minimal example and what you expected to happen.
  • Request features — describe the feature and how you’d expect it to behave.
  • Submit pull requests — bug fixes, codegen, new syntax, tests.
  • Improve the docs & this site — typos, clarifications, and new examples all help.

Everything lives on GitHub.

Before you start, read the CONTRIBUTING.md in the repository — it has the full guidelines and code style rules.

Getting started

Prerequisites

A C compiler (e.g. gcc), make, and git.

Clone and build

git clone https://github.com/tanvir-techbro/PiNum-Lang.git
cd PiNum-Lang
make

Run the example

./bin/pinum example/demonstration.pn

Project structure

See the roadmap for the full breakdown.

Opening a pull request

  1. Fork the repo and create a branch: git checkout -b my-feature
  2. Make your changes and build: make
  3. Confirm the example still runs: ./bin/pinum example/demonstration.pn
  4. Commit with a clear message, push, and open a pull request against the development branch.
Always open pull requests against the development branch — not main. Keep PRs small and focused — one feature or fix per PR makes review much easier.

Good first issues

Everything on the roadmap is open territory. The most useful contributions right now are:

  • Function definitions & calls
  • Data structures — arrays (int arr[5]) and structs
  • switch / case
  • Runtime library expansion
