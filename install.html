Installation

Get PiNum running in a few minutes.

1

One-line install

The fastest way to install PiNum on Linux/macOS:

curl -sSL https://raw.githubusercontent.com/tanvir-techbro/PiNum-Lang/main/install.sh | bash
2

Prerequisites

A C compiler (e.g. gcc) and make.

3

Build from source

git clone https://github.com/tanvir-techbro/PiNum-Lang.git
cd PiNum-Lang
make

The binary lives in the bin/ directory. Add it to your PATH with sudo make install.

4

Run a program

PiNum files use the .pn extension:

./bin/pinum example/helloworld.pn
Windows: PiNum supports Linux/macOS only. Use WSL and follow the Linux instructions.

Editor support

Syntax highlighting is bundled in the repo under extras/.

  • VS Code: extension at extras/vscode/
  • Neovim: run ./activate_syntax.sh from the repo root
