Installation

Get PiNum running in a few minutes. There are two ways to install it: the one-line curl script, or building from source.

Option 1 · One-line install

The fastest way to install PiNum on Linux/macOS. The script downloads, builds, and installs the binary for you:

curl -sSL https://raw.githubusercontent.com/tanvir-techbro/PiNum-Lang/main/install.sh | bash

Option 2 · Build from source

Prefer to build it yourself, or want the latest changes? Follow these steps.

1

Install prerequisites

A C compiler (e.g. gcc) and make.

2

Clone the repository

git clone https://github.com/tanvir-techbro/PiNum-Lang.git
cd PiNum-Lang
3

Build

make
4

Install the binary (optional)

The binary lives in the bin/ directory. Add it to your PATH with:

sudo make install

Run a program

However you installed it, PiNum files use the .pn extension:

pinum example/helloworld.pn

If you skipped sudo make install, run it straight from the build output:

./bin/pinum example/helloworld.pn
Windows: PiNum supports Linux/macOS only. Use WSL and follow the Linux instructions.

Editor support

Syntax highlighting is bundled in the repo under extras/.

  • VS Code: extension at extras/vscode/
  • Neovim: run ./activate_syntax.sh from the repo root
