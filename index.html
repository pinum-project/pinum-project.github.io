Quick start

Hello, PiNum.

Install it in one line, save a file, run it.

curl -sSL https://raw.githubusercontent.com/tanvir-techbro/PiNum-Lang/main/install.sh | bash

Save the following as example.pn:

string name = "world"
print("Hello, ", name, "!\n")

int a = 10
int b = 3
print(a + b, "\n")          # 13
print(a > b, "\n")          # true
print(a > b ? "a wins" : "b wins", "\n")

Then run it:

pinum -o example example.pn
Features

Why PiNum?

Everything you expect, nothing you don’t.

C-style syntax

Familiar types and control structures that are easy to pick up.

Simple I/O

print() and read() handle output and input with zero setup.

Rich operators

Arithmetic, logical, bitwise, and ternary operators, plus ++/-- and compound assignment.

Editor support

Syntax highlighting for VS Code and Neovim included.

Clean pipeline

Custom lexer, AST, and parser written in C.

Easy install

One-line script on Linux/macOS, or build with make.
