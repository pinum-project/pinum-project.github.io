Playground

Write PiNum, hit Run, and watch it execute right here. Your code is transpiled to C, compiled to WebAssembly, and run in this tab — nothing leaves your browser.

Load:
main.pn
Output

First run downloads the in-browser C compiler (a few tens of MB), so it can take a moment. Subsequent runs are much faster. Currently the compiler lives on jsDelivr’s CDN; we plan to self-host it.
