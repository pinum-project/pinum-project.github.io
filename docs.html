Documentation

A guide to the PiNum syntax. The language is under active development, so the spec may evolve.

On this page

Comments Imports & directives Variables & types Operators Conditions Loops Input & output

Comments

Single-line comments start with #.

# this is a comment!
# there is only single line comments.

int a = 1;   # comments can appear after code too

Imports & directives

Directives begin with @. Pull in the standard library with @import.

@import stdlib   # standard library
@import math     # math library

Engine mode

The @for engine flag transpiles PiNum into bare C.

If you include this flag, you can’t import any libraries.
@for engine

Variables & types

Declare a variable by writing its type followed by its name. Modifiers like long, short, unsigned, and signed are supported.

Basic types

Type Example Description
intint count = 10;Whole numbers
floatfloat ratio = 3.5;Floating point
doubledouble pi = 3.14159;Double precision float
charchar letter = 'A';A single character
stringstring name = "pinum";Text
boolbool done = true;true or false
 
int count = 10;
float ratio = 3.5;
double pi = 3.14159;
char letter = 'A';
string name = "pinum";
bool done = true;

Declaring without a value

You can declare a variable and assign a value later.

int a;
a = 5;

Type modifiers

unsigned int u = 2147483647;
signed int si = -5;
long int li = 123456789;
long double ld = 0.123456789;
short int sh = -32768;

Operators

Standard arithmetic, comparison, logical, and bitwise operators, plus a ternary conditional.

Arithmetic

int a = 10;
int b = 3;
print(a + b, "\n");   # 13
print(a - b, "\n");   # 7
print(a * b, "\n");   # 30
print(a / b, "\n");   # 3
print(a % b, "\n");   # 1

Comparison & logical

print(a > b, "\n");    # true
print(a == b, "\n");   # false

bool t = true;
bool f = false;
print(t && f, "\n");   # false
print(t || f, "\n");   # true

Ternary

condition ? then : else

int max = a > b ? a : b;
print(max, "\n");

Conditions

if (condition) {
    # task 1
} else if (condition) {
    # task 2
} else {
    # default task
}

Loops

There are two loops: for and while.

For loop

for (variable; condition; increment or decrement) {
    # task
}

While loop

while (condition) {
    # task
}

Input & output

Output with print(), input with read().

@import stdlib

int number = 10;
print(number, "\n");
print("hello ", number, "\n");
