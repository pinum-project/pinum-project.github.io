Documentation

A guide to the PiNum syntax. The language is under active development, so the spec may evolve.

On this page

Comments

Single-line comments start with #.

# this is a comment!
# there is only single line comments.

int a = 1   # comments can appear after code too

Semicolons are optional

Statements end at a newline, so you don’t need semicolons:

int a = 10
int b = 3
print(a + b, "\n")

Use semicolons only when you want to put multiple statements on a single line:

int a = 1; int b = 2; print(a + b, "\n")

Variables & types

Declare a variable by writing its type followed by its name. Modifiers like long, short, unsigned, and signed are supported.

Declaring without a value

You can declare a variable and assign a value later.

int a
a = 5

Type modifiers

unsigned int u = 2147483647
signed int si = -5
long int li = 123456789
long double ld = 0.123456789
short int sh = -32768

Operators

Standard arithmetic, comparison, logical, and bitwise operators, plus a ternary conditional.

Arithmetic

int a = 10
int b = 3
print(a + b, "\n")   # 13
print(a - b, "\n")   # 7
print(a * b, "\n")   # 30
print(a / b, "\n")   # 3
print(a % b, "\n")   # 1

Increment & compound assignment

++ and -- adjust by one; +=, -=, *=, /=, and %= are shortcuts for x = x op y.

int i = 0
i++              # i is now 1
i--              # i is now 0

int a = 10
a += 5           # 15  (a = a + 5)
a -= 3           # 12
a *= 2           # 24
a /= 4           # 6
a %= 4           # 2

String & char repetition

Multiply a string or a character by an integer to repeat it:

string s = "ab" * 3
print(s, "\n")         # ababab

char c = 'x'
print(c * 4, "\n")     # xxxx

Comparison & logical

print(a > b, "\n")    # true
print(a == b, "\n")   # false

bool t = true
bool f = false
print(t && f, "\n")   # false
print(t || f, "\n")   # true

Ternary

condition ? then : else

int max = a > b ? a : b
print(max, "\n")

Conditions

if (condition) {
    # task 1
} else if (condition) {
    # task 2
} else {
    # default task
}

Loops

There are two loops: while and for.

While loop

while (condition) {
    # task
    if (something) {
        break      # exit the loop
    }
    if (something_else) {
        continue   # skip to the next iteration
    }
}

For loop

Follows the classic for (init; condition; increment) shape:

for (int i = 0; i < 5; i++) {
    print(i, "\n")
}

for (int k = 0; k < 10; k += 2) {
    print(k, "\n")   # 0 2 4 6 8
}

for (;;) {
    # infinite loop — use break to exit
}

Input & output

Output with print(), input with read(). The standard library is included automatically.

int number = 10
print(number, "\n")
print("hello ", number, "\n")

int data
print('Enter a number: ')
read(data)
print("you entered ", data, "\n")
