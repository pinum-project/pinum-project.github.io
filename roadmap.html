Development status

PiNum is at v1.3.0-beta. The lexer, AST, parser, and code generation for the current feature set are complete — including collections (vec<T>), arrays, functions, method calls, and range loops. Next up are structs/objects, switch, and a native backend.

Done

  • Done Lexer / tokenizer
  • Done AST construction
  • Done Parser
  • Done Variable declarations & assignments
  • Done Blocks and if / else
  • Done while loops
  • Done for loops
  • Done return, break, continue
  • Done Ternary operator
  • Done ++ / -- and compound assignment (+=, -=, *=, /=, %=)
  • Done String & char repetition ("s" * n, 'c' * n)
  • Done Full expression grammar
  • Done Codegen: literals, expressions, print(), read()
  • Done Codegen: if / else, while, for, return, break, continue
  • Done Range loops (for (n) { })
  • Done println() — print() with a trailing newline
  • Done Vectors vec<T> — literal syntax […], element access, and bounds-checked writes
  • Done Vector methods & properties (.append(x), .size) via the method table
  • Done Arrays (int arr[5]) with read & write access (arr[i], arr[i] = x)
  • Done Method calls & member access (obj.method(args), obj.prop)
  • Done Function definitions & calls (fn name(params) -> type { }, recursion)
  • Done @for engine bare-C transpile directive
  • Done Initial runtime library

In progress

  • WIP Structs / objects & member definitions
  • WIP Native backend (QBE) alongside the C backend
  • WIP Centralized builtin & type-mapping tables

Up next

  • Planned switch / case
  • Planned Runtime library expansion (more vector methods, string ops)
